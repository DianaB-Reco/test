# Test Project

A small sample JavaScript project with source code and unit tests.

## Files

- `src/index.js` - application entry point
- `src/math.js` - sample math utility functions
- `tests/math.test.js` - Jest unit tests
- `package.json` - project metadata and scripts

## Usage

Install dependencies:

```bash
npm install
```

Run tests:

```bash
npm test
```

Run the sample app:

```bash
npm start
```
